# MCP Apps · מדריך

מדריך כללי ל-MCP Apps: רכיבים אינטראקטיביים ששרת MCP מציג בתוך הצ'אט של ChatGPT, של Claude ושל מארחים נוספים. למנהלי מוצר, לגורמים עסקיים ולארכיטקטים.

- **הדף:** `index.html`, קובץ אחד בלי שלב בנייה. נפתח בכל דפדפן, במחשב ובטלפון.
- **עובדות:** כל עובדה מקושרת למקור רשמי שנבדק ב-3/11/2026. מה שלא אומת מסומן "לאמת".
- **עיצוב:** מערכת העיצוב של מגדל. הפונט והלוגו ב-`fonts/` וב-`assets/`.
